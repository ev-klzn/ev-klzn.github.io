# Збирання стилів і скриптів

Сторінки сайту підключають `assets/css/style.min.css` і `assets/js/script.min.js`, а в `<head>` кожної сторінки вбудовані критичні стилі. Правки в `assets/css/style.css` і `assets/js/script.js` потрапляють на сайт лише після запуску цього інструмента.

Папка `_tools` на сайт не публікується.

## Перший запуск

Потрібні Node.js і встановлений Google Chrome.

```
cd _tools
npm ci
```

## Коли запускати

Після будь-якої правки в `style.css` чи `script.js`, а також після зміни HTML на першому екрані сторінки або додавання нової сторінки:

```
cd _tools
npm run build
```

Інструмент:

1. створює `style.min.css` і `script.min.js`;
2. у реальному браузері на 17 розмірах екрана визначає, які правила потрібні для першого екрана кожного типу сторінки;
3. оновлює критичні стилі в усіх HTML-файлах, зокрема в `en/`.

Повторний запуск без правок нічого не змінює. Нові сторінки в корені чи в `en/` підхоплюються самі, якщо в їхньому `<head>` є один із двох варіантів підключення стилів: уже оброблений блок або `<link rel="stylesheet" href="./assets/css/style.css">`.

## Що правити

| Що змінюємо | Де |
|---|---|
| Стилі | `assets/css/style.css` |
| Скрипти | `assets/js/script.js` |
| Текст і розмітка | HTML-файли сторінок, обидві мовні версії |

Файли `.min` і блок `<style>` у сторінках вручну не правимо: наступний запуск їх перезапише.

У коді проєкту не використовуємо коментарі.
